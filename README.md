# 國王遊戲

手機開局的派對遊戲。朋友各自用瀏覽器加入同一間房，不用下載 App。每一輪秘密抽牌：一個人是國王，其他人是號碼。國王只對號碼下命令，主持人再揭曉被點到的是誰。

也有單機模式，把同一支手機傳下去就能玩，不需要連房間。

## 本機執行

需要 Node.js 20 以上。

```bash
npm install
npm start
```

瀏覽器打開 [http://localhost:4721](http://localhost:4721)。服務會聽 `0.0.0.0` 和 `PORT`（沒設定時是 4721）。

改檔時可以用：

```bash
npm run dev
```

檢查規則與連線：

```bash
npm test
```

## 怎麼玩

1. 主持人按「開一間房」，把 4 碼房間代碼、QR 或連結傳給朋友。
2. 朋友輸入暱稱加入。至少 3 人、最多 12 人，主持人就能開始。
3. 每支手機只看得到自己的牌。國王從指令庫抽一條，或自己寫，然後公布。
4. 主持人按「揭曉是誰」。被點到的號碼會標出來，國王也會亮相。
5. 不想做就直接說，沒有懲罰。主持人再開始下一回合。

重新整理頁面會用這台裝置上存的連線回到原來的房間。中途按「離開」會先問一次。主持人可以移出玩家；若命令還沒公布，這一輪會重發。

指令庫分「輕鬆破冰 / 普通 / 刺激」，內容停在聚會能做的小挑戰，沒有喝酒，也沒有親密或脫衣指令。自己寫的命令就由現場的人自己拿捏。

## 部署到 Render

倉庫裡有 `render.yaml`，可以當 Blueprint 建立一個 Node 網站服務。它會：

- `npm install` 之後執行 `npm start`
- 聽 Render 提供的 `PORT`
- 用 `/health` 做健康檢查
- 維持 1 個實例

房間狀態放在記憶體裡，所以不要開多個實例，重新部署或重開機後房間會清空。免費方案閒置約 15 分鐘會休眠，下一個人進來會冷啟動；若要整晚開著玩，把方案調高即可。

Render 的網站服務支援 WebSocket，這個遊戲的即時同步走 Socket.IO。

## 專案結構

- `server.js`：Express + Socket.IO，靜態檔與房間事件
- `lib/game.js`：發牌、命令、揭曉、離開與重連
- `public/`：手機優先的介面，含單機模式
- `test/`：發牌隱私與多客戶端回合
